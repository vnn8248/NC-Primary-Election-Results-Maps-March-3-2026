# Data sources

## Election results

North Carolina State Board of Elections precinct-level election results.
[NCSBOE Election Results](https://www.ncsbe.gov/results-data/election-results)

## Precinct geography

North Carolina statewide precinct geography corresponding to the election period.
[NCSBOE Voting Maps/ Redistricting](https://www.ncsbe.gov/results-data/voting-maps-redistricting)

## Coordinate systems

Source precinct geography is retained in its projected CRS for analysis.

GeoJSON files are reprojected to EPSG:4326 before web export.
